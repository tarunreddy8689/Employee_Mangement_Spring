# Employee Management (VEDTS) - Frontend (React + Vite)

This is a starter React + Vite frontend for an Employee Management System tailored for VEDTS.

## Features
- React 18 + Vite
- React Router v6
- Material UI (MUI)
- Framer Motion animations
- MUI Snackbar notification system (global)
- Dummy service using localStorage to simulate backend API
- Routes: /, /add, /edit/:id

## Setup
```bash
npm install
npm run dev
```

Open http://localhost:5174

The dummy data is persisted in localStorage under key `vedts_employees_v1`.
